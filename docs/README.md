# Documentation

Start with the document that matches the task:

- [Getting started](getting-started.md) explains the current user API with
  executable examples.
- [Understanding solver decisions](understanding-decisions.md) explains how
  to distinguish an answer, a proved obstruction, and an unsupported input.
- [Architecture and roadmap](design.md) maps the implementation to the Risch
  algorithm and states the remaining boundaries.
- [Mixed transcendental towers](mixed-transcendental-towers.md) states the
  supported primitive/hyperexponential/hypertangent contract.
- [Algebraic function-field infrastructure](algebraic-infrastructure.md)
  specifies maximal orders, fractional ideals, places, valuations, local
  expansions, divisors, and differentials.
- [Checked monogenic extension fields](monogenic-extension-field.md) describes
  the independent exact coefficient-field replacement and its current
  factorization boundary.
- [Mathematical testing contract](testing.md) defines the verification
  required for each checkpoint.
- [Tutoring notes](tutoring-notes.md) introduce the mathematics in a guided
  sequence.
- [Algebraic-over-hypertangent research note](algebraic-hypertangent.md)
  explores a possible future real-algebraic branch.

The README at the repository root gives installation and test commands.
